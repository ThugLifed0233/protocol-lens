# Public results

This directory is the intended home for reviewed, derived Protocol Lens results.

Keep these items on the local Mac:

- an Apple Health export;
- exact intervention dates;
- doses or personal notes;
- raw health measurements;
- personally identifying information.

The local app can export a publishable JSON or CSV snapshot. Before committing one:

1. read the entire file;
2. confirm every intervention is safe to name publicly;
3. verify that no exact date, dose, note, or raw value appears;
4. remember that a derived result can still reveal personal information;
5. commit only after explicit approval.

`example.json` uses synthetic values and documents the output shape.
